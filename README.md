# AI-Labs

A collection of Python-based laboratory exercises focused on Artificial Intelligence and Cybersecurity concepts. This repository contains hands-on programming tasks designed to help students learn fundamental programming concepts, object-oriented programming (OOP), and AI-powered cybersecurity applications.

## 📚 Contents

This repository contains the following lab notebooks:

- **Lab-01.ipynb** - Python Fundamentals
- **Lab-02.ipynb** - Object-Oriented Programming with Cybersecurity Applications

## 🎯 Lab Descriptions

### Lab 01: Python Fundamentals
This lab covers basic Python programming concepts through 7 practical tasks including:
- User input and data handling
- Conditional statements
- Data structures (dictionaries, lists)
- Control flow and decision making
- Basic Python operations

### Lab 02: OOP with AI-Powered Cybersecurity
This lab focuses on Object-Oriented Programming principles applied to cybersecurity scenarios:

**Task 1: Security Agent Management System**
- Develop an AI-powered cybersecurity system with base class `SecurityAgent`
- Implement derived classes: `FirewallAgent`, `MalwareDetectionAgent`, `AutomationAgent`
- Create type-specific methods for different security operations

**Task 2: Threat Intelligence Tracking**
- Build an AI-based threat intelligence system
- Track different threat types: `PhishingThreat`, `RansomwareThreat`, `BotnetThreat`
- Implement threat monitoring and detection

**Task 3: Automated Threat Response**
- Design automated response agents: `AlertAgent`, `BlockAgent`, `RecoverAgent`
- Implement polymorphic `execute_response()` method
- Demonstrate different response strategies

**Task 4: Employee Management System**
- Create employee hierarchy with base class `Employee`
- Implement role-specific behavior for `Manager`, `Developer`, `Designer`
- Demonstrate method overriding and polymorphism

**Task 5: Student Grading System**
- Build a student grading system with encapsulation
- Implement private attributes and getter/setter methods
- Practice data hiding and access control

## 🛠️ Prerequisites

- Python 3.x
- Jupyter Notebook or JupyterLab
- Basic understanding of Python programming

## 🚀 Getting Started

1. Clone this repository:
```bash
git clone https://github.com/thetalhamirza/AI-Labs.git
cd AI-Labs
```

2. Install Jupyter Notebook (if not already installed):
```bash
pip install jupyter
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```

4. Open the desired lab notebook and start working through the exercises.
